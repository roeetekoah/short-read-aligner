# Reproduce the local release candidate

## Runtime

CPython 3.10+; tested here with 3.13.13 on Windows 11. The implementation, tests, fixtures and benchmarks need only the standard library. No reference genome download, course data, external aligner, AI service or credentials are required. All commands below run from the repository root.

```console
python -m short_read_aligner --help
python -m short_read_aligner --reference examples/reference.fa --reads examples/reads.fastq --output example.tsv
python tools/check.py
python tools/make_fixtures.py --check
python benchmarks/run.py --output benchmark-output
```

Use a new output path on each CLI run; `example.tsv` is deliberately refused if it already exists. `tools/check.py evidence/tests-new.json` additionally writes a machine-readable test result. `python -m unittest discover -s tests -v` runs the same test cases without the evidence wrapper. Tests use temporary directories under the ignored `output/` directory, avoiding dependence on system temp permissions. Benchmarks overwrite their chosen result files; select a new output directory to preserve an earlier run.

`tools/make_fixtures.py --check` verifies exact generated bytes, including the seven-record expected output computed by the exhaustive oracle. Running it without `--check` regenerates the committed synthetic fixtures and manifest. The benchmark validates all input hashes before measurement. It performs a warm-up and at least three untraced timing repeats; the optional `--repeats N` must be ≥3. Run it on an otherwise quiet machine. Raw repetitions, environment, source/input fingerprints, correctness counts and inspected per-read results are saved with the summary.

## Optional isolated installation

In PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\short-read-aligner.exe --version
```

In a POSIX shell:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -e .
.venv/bin/short-read-aligner --version
```

Installation may obtain the build backend; `pyproject.toml` requires setuptools≥68. No runtime dependencies are installed. Direct `python -m short_read_aligner` execution avoids that build dependency entirely. Only the Windows/3.13 route was exercised locally; the Python minimum and POSIX commands follow the code/interface requirements but are not a tested platform matrix.

## Historical-like heuristic configuration

```console
python -m short_read_aligner --reference examples/reference.fa --reads examples/reads.fastq --output historical-like.tsv --k 15 --max-mismatches 2 --max-hits-per-seed 200 --early-exit
```

This selects the old fast run's core parameters, not the old benchmark environment, dataset, historical implementation or timings. `exact-hit-truncated` marks zero-mismatch results whose other best hits were not counted. For minimizers, add `--minimizer-window 4`; both the index and query seeding then use that window automatically. These modes need not be complete for short reads.

## Reading the output

TSV rows preserve input order. Interval `[start,end)` refers to the forward reference even when strand is `-`. Unmapped coordinates/strand are `.`, mismatch count is budget+1 and `n_best=0`. A count of one is a claim about retrieved candidates unless the completeness assumptions hold; it is not a mapping-quality probability. Detailed input, error and tie behavior is in [contract.md](contract.md).
